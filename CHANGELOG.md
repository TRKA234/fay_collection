# Changelog - Fay Collection

## Version 1.0.0 (2026-01-04)

### Features
- ✅ Sistem e-commerce lengkap untuk produk rajut handmade
- ✅ Manajemen produk dan kategori
- ✅ Shopping cart system
- ✅ Checkout dengan pilihan pengiriman (JNT / Ambil di Lokasi)
- ✅ Manajemen pesanan untuk admin
- ✅ Update status pesanan real-time
- ✅ Update ongkos kirim langsung di halaman detail
- ✅ Email notifications untuk customer dan admin
- ✅ Role-based authentication (Admin & Customer)
- ✅ Informasi pembayaran dan pengiriman
- ✅ 22 produk dummy dengan kategori lengkap

### Technical
- Laravel 12.31.1
- PHP 8.4.8
- Bootstrap 5.3.3
- MySQL Database

### Security
- Role-based access control
- CSRF protection
- Password hashing
- Input validation
